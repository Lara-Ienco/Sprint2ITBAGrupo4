## 📝 Descripción del proyecto

Esta página web está dedicada a los productos de los Hermanos Jota. Permite a los usuarios explorar los productos de manera interactiva y atractiva. Se implementó un diseño *mobile-first* y totalmente *responsivo*, adaptándose a cualquier tamaño de pantalla.

El sitio incluye:

* Un *catálogo de productos* con su propio HTML y CSS.
* Navegación desde el index.html hacia secciones como *Catálogo* y *Contacto*.
* Páginas individuales para cada producto con su descripción y detalles.
* Un *carrito de compras, que se muestra como **modal* con información resumida de los productos seleccionados.
* Un *carrusel de productos* interactivo usando *JavaScript y CSS* para mejorar la experiencia de usuario.

## 🛠 Tecnologías utilizadas

* *HTML5*
* *CSS3* (Flexbox para layout y animaciones)
* *JavaScript* (carrusel de productos, modal de carrito, navegación interactiva)
* *Git/GitHub* (control de versiones)

## 🚀 Funcionalidades principales

* Diseño *responsive* y *mobile-first*.
* *Carrusel de productos* con animaciones suaves.
* *Catálogo de productos* con páginas individuales y estilos propios.
* *Navegación intuitiva*: menú con enlaces a Catálogo, Contacto y productos específicos.
* *Carrito modal* que muestra un resumen de los productos seleccionados.
* Animaciones y transiciones para mejorar la experiencia de usuario.

## ⚡ Uso

1. Abrir index.html en un navegador moderno.
2. Navegar por el menú a *Catálogo* o *Contacto*.
3. Seleccionar un producto en el catálogo para ver sus detalles.
4. Visualizar el carrito como modal desde el navbar.
